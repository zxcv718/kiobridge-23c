# 시안을 코드로 옮길 때의 판단 기준

이 문서는 **취향이 아니라 이미 내려진 결정**을 적어 둔 것이다. 화면을 여럿이 나눠 맞출 때
각자 다르게 판단하면, 기획이 지적한 「디자인을 반영한 것 같은데 두 개가 섞인」 화면이
셋 넷으로 늘어난다. 새 판단이 필요하면 여기 적고 나서 하는 것이 순서다.

- 파일 키 `nrI4zQXqae1vzrnDPibpMC`
- 기획 지시: **「있는 화면은 시안 그대로. 있는 걸 판단하지 말고 없는 걸 판단해라.」**

---

## 1. 대전제

**시안에 있는 것은 시안이 정한다.** 문구·색·굵기·크기·여백·좌우 순서 전부 포함이다.
「우리 것이 더 낫다」는 이 자리에서 근거가 되지 못한다.

**시안이 다루지 않은 것만 우리가 정한다.** 시안에 없는 상태(저장본이 있는 경우, 오류,
빈 목록…), 시안에 없는 요건(무로그인 가이드·접근성 보증), 시안에 없는 화면이 그것이다.

---

## 2. 이미 내려진 결정 — 그대로 따른다

### 2.1 시안에 없는데 요건상 필요한 것 → **접는다**
`<details class="home-saved">` 한 줄로 접어 둔다. 펴기 전 화면이 시안과 같아지고,
필요한 사람은 한 번 눌러 닿는다. 이미 이렇게 처리한 것:
저장된 내용 조회·수정(홈) · 저장되는 항목 설명(S03) · 이번 화면 설정(S05).

### 2.2 시안 문구를 쓰되 **동작이 다르면** 우리 문구
시안 라벨을 붙였는데 그 버튼이 시안이 그린 적 없는 일을 하면, 이름과 하는 일이 어긋난다.
그럴 때만 우리가 적는다. 예: 저장본에 7문항이 다 있으면 「이전 화면 설정 사용」이 아니라
「지난번과 똑같이 주문하기」(마법사를 통째로 건너뛰므로).

### 2.3 시안 문구가 참이 되도록 **동작을 고친다**
문구를 바꾸는 것보다 이쪽이 먼저다. 예: 「글자를 20% 크게」 → `--fs-large` 를
`calc(var(--fs-base) * 1.2)` 로. 「다음에 누를 버튼을 테두리와 화살표로 강조」 →
실제로 구현(`.app.guide`).

### 2.4 색은 시안 값, 미달은 **표에 수치로** 남긴다
`tests/tokens.test.ts` 의 `시안예외` 표에 색쌍과 소수점 수치까지 적는다. 표에 없는 미달은
전부 실패한다. 고대비 팔레트에는 예외가 **하나도 없다**. README 알려진 제한사항의 숫자와
같아야 한다.

### 2.5 굵기
CTA 라벨은 **Regular 400**(208:755 `font-normal`). 제목·요약 값·현재 단계 라벨은
**Bold 700**. 800 은 쓰지 않는다.

**선택지 라벨은 타일이든 줄이든 Regular 400 이다.**

| | 예 | 굵기 | 시안 |
|---|---|---|---|
| 아이콘 **있는** 타일 | 뼈·순살 / 매장·포장 / 알레르기 게이트 | Regular 400 | `I99:1278;38:1935` |
| 아이콘 **없는** 줄 | 순한맛·보통맛·매운맛 | Regular 400 | `282:1180` |
| | 알레르기 목록 | Regular 400 | `I99:1258;66:1785` |

한때 아래 줄이 **Bold 700** 이었고 근거로 `I99:1268;56:433` 을 적어 두었다. **그 노드는
지금 시안에 없다** — 맵기의 선택지 목록이 `282:1082` 로 통째로 교체되면서 사라졌고,
새 목록의 라벨은 Regular 다. 함께 적혀 있던 알레르기 목록은 교체된 적도 없는데
(`99:1257` 그대로다) 그 라벨도 처음부터 Regular 였다 — 즉 맵기 노드 하나에서 읽은 것을
목록 전체로 넓힌 것이었고, 그 하나마저 지금은 다른 값이다.

교훈은 두 가지다. **규칙에 적혀 있다는 것이 시안에서 나왔다는 뜻은 아니다** — 근거 노드가
몇 개인지, 그것이 같은 종류인지를 보고 적을 것. 그리고 **근거 노드는 사라진다** — 시안이
바뀌면 여기 적힌 노드 번호부터 다시 열어 볼 것. 2026-08-12 에 여섯 화면을 다시 대조하며
찾았다.

### 2.6 터치 타깃 48px 은 시안보다 우선한다
시안의 44px 아이콘 박스·45px 요약 행보다 크게 둔다. 제출물에 선언한 보증이고
`tests/a11y.test.ts` 가 `cursor: pointer` 규칙을 전수로 잰다. 이때 생기는 3~4px 차이는
받아들인다.

### 2.7 「아이콘 단독 금지」는 **접근 가능한 이름**을 뜻한다
`aria-label` 이 있으면 화면에 아이콘만 두어도 된다(뒤로가기가 그 예다).

### 2.8 없는 기능을 있다고 표시하지 않는다
동작하지 않는 링크·버튼을 시안에 있다는 이유로 만들지 않는다. 반대로 선언한 것은
화면에서 실제로 닿아야 한다.

## 3. 이미 맞춰 둔 공통 값 — 다시 정하지 말 것

| | 값 | 근거 |
|---|---|---|
| 화면 여백 | 좌우 24px · 위 40px · 아래 40px | 모든 프레임 `px-24 py-40` |
| 화면 폭 | `--kb-screen-max: 402px` | 시안 프레임 |
| CTA | 354×56 · radius 12 · primary `#ff5a1f`+흰 글씨 · white 흰 바탕+1px 테두리 | 208:754 / 208:756 |
| 제목 | 22px Bold (`.kb-title` 1.22em) | 150:184 등 |
| 강조어 | 28px (`.kb-title-key` 1.27em) — **질문 화면 문법이다**, 홈·프로필에는 없다 | 99:1276 |
| 부제 | 15px `.kb-subtitle` 0.83em · 색은 화면마다 다름(`subtitleStrong` 로 tertiary) | 150:185 / 150:302 |
| 고객님, | 18px `.kb-eyebrow` 1em · 제목과 6px | 99:1275 |
| 요약 카드 | 테두리 1px `--line-card` · 안쪽 `4px 16px` · radius 16 | 185:209 |
| 요약 행 | 45px · 14px(0.78em) · 라벨 `--muted-strong` · 값 Bold | 185:210 |
| 행의 «수정» | Medium 500 · `--brand` · 밑줄 없음(닿을 때만) | 185:214 |
| 진행 표시 | 첫 점 왼쪽 = 본문 왼쪽 선, 마지막 점 = 오른쪽 선 | 181:177 |
| 선택지 그림 | **항상** 표시 (설정과 무관) | 99:1228·99:1270 등 |

색은 **의미 이름만** 쓴다(`--fg` `--muted` `--muted-strong` `--line` `--line-card`
`--line-soft` `--brand` `--brand-strong` `--card` `--sunken` `--selected`).
`--kb-…` 원시 토큰을 화면 CSS 에서 직접 쓰면 고대비 모드가 그것만 못 갈아끼운다.

## 4. 레인 규칙 (여럿이 나눠 맞출 때)

**공용 파일은 손대지 않는다.** 필요하면 «무엇을 왜» 보고만 한다:
`ui/src/styles.css` · `ui/src/components.css` · `ui/src/tokens.css` ·
`ui/src/model.ts` · `ui/src/components/*.tsx` · `ui/src/flow.tsx` ·
`tests/e2e/nav.ts` · `tests/tokens.test.ts` · `participant-ux.json` · `src/core/**`

**git 명령을 실행하지 않는다.** 커밋·푸시·배포·제출물 재생성은 통합하는 쪽이 단독으로 한다.

**화면 문구를 바꿨으면 그 문구를 쓰는 e2e 도 같이 고친다.** 다만 `nav.ts` 는 공용이므로
거기 고칠 것이 있으면 보고한다.
