## 2. 평가 요건과 충돌하는 4건 — 결정이 필요하다

시안을 절대 기준으로 두면 아래 넷은 **우리가 제출물에 선언한 보증**을 깬다.
디자인 취향 문제가 아니라 심사 항목이라 그대로 넘기지 않고 적는다.

### C-1. 보조 텍스트 #8c8c8c → 흰 배경에서 **3.36:1** (AA 4.5 미달)

- 지금 #45454d 로 바꿔 둔 이유가 이것이고, `tests/contrast.test.ts` 가 계산기로 잡는다.
- 시안대로 되돌리면 **대비 검사 12건이 실패**하고, 제출물의 접근성 근거와도 어긋난다.
- **제안: 색은 시안 값을 쓰되 크기를 15px 로 맞추고, 대비 미달은 README 알려진 제한사항에 명시.**
  또는 #767680(4.54:1) 처럼 **눈으로 구분 안 되는 최소 조정**으로 AA 를 지킨다 ← 권장

### C-2. 직원 도움 버튼이 시안에 없음

- 우리 보증 `staffHelpReachableFromEveryStep: true` · `tests/a11y.test.ts` 가 전 화면 강제.
- 없애면 보증을 내려야 하고(`participant-ux.json`), **키오스크 접근성 서비스에서 비상구를 없애는 것**이다.
- **제안: 시안에 없는 «화면»이 아니라 «요소»이므로 §1 의 «시안에 없는 것은 현행 유지» 범위로 본다.
  다만 머리 줄에서 **더 작고 조용하게**(고스트·아이콘+글자) 두어 시안 인상을 해치지 않는다.** ← 권장

### C-3. 재방문 홈의 저장 기록 카드·수정·삭제가 시안에 없음

- 무로그인 가이드 §4 「저장된 정보를 **조회·수정·삭제**할 수 있어야 합니다」 정면 충돌.
- **제안: 카드를 시안대로 없애는 대신 «저장된 내용 보기»를 눌러 펼치는 형태로.
  첫 화면 인상은 시안과 같아지고 조회·수정·삭제는 한 걸음 안에 남는다.** ← 권장

### C-4. 뒤로가기 글자 제거 → 「아이콘 단독 버튼 금지」 보증

- 시안대로 chevron 만 두되 `aria-label="뒤로"` 를 준다. 화면 낭독기에는 이름이 있고 화면에는 아이콘만 —
  **WCAG 위반이 아니다.** 우리 규칙을 «보이는 글자» 대신 «접근 가능한 이름»으로 고쳐야 한다.
- **제안: 규칙과 검사를 그 정의로 바꾼다.** ← 권장 (보증은 유지되고 시안도 지켜진다)

## 3. 단계별 작업

**Phase 1 — 토대 (다른 모든 화면에 영향)**
1. Noto Sans KR 웹폰트를 **자체 호스팅**으로 싣는다. CDN 링크는 시연장 네트워크에 기댄다.
   서브셋 woff2 를 `ui/public/fonts/` 에 두고 `@font-face` + `font-display: swap`.
2. 타이포 토큰을 시안 값으로 정렬 — 제목 22px Bold / 부제 15px Regular / 본문 18px.
3. 배경 `#ffffff`, 패딩 24px·40px, CTA 폭·높이(354/56) 정렬.
4. C-1 결정에 따라 보조 텍스트 색 확정.

**Phase 2 — 공통 부품**
5. `Header` 를 시안대로: 44px 원형 sunken 배경 + chevron 24px, **글자 제거 + aria-label**.
6. 「아이콘 단독 금지」 규칙·검사를 «접근 가능한 이름»으로 재정의(C-4).
7. 홈에도 뒤로가기 배치(시안 B) — 누르면 어디로 갈지 정의 필요(첫 화면이므로 «없음»이 맞을 수도. 확인 요청).

**Phase 3 — 화면별 정렬 (시안 있는 화면만)**
8. S01a 홈(최초): `p-note` 제거, 구성 = 뒤로 → 진행표시 → 제목 → 부제 → 여백 → [시작하기].
9. S01b 홈(재방문): 카드를 접기(C-3), 버튼 2개만 남김.
10. S02 1~3단계: 라디오 카드 시안 정렬.
11. S06~S10, S12~S15: 시안과 1:1 대조표를 만들어 어긋난 것만 고친다.

**Phase 4 — J·K (기능 정의 교체, 가장 큰 작업)**
12. 선택지 그림을 **항상 표시**로 바꾼다(`showIcons` 분기 제거).
13. `visualGuidance` 를 시안 정의대로 **«다음에 누를 버튼을 테두리와 화살표로 강조»**로 재구현.
14. 접근성 선언(`participant-ux.json`·`accessibilityEvidence`)의 VISUAL_GUIDANCE 설명을 바꾼다.
15. **제출물 재생성**(SHA 변경) — 선언 문구가 제출물에 들어가므로.

**Phase 5 — 검증**
16. `tsc` · 단위 134 · e2e 105 · 조합 12,960 전부. 대비 검사는 C-1 결정에 따라 기대값 조정.
17. 시안 대비 육안 확인(실기기 2종) — 자동으로 못 재는 부분.

## 4. 되돌릴 수 없는 것 / 위험

- **Phase 4 는 제출물을 바꾼다.** SHA·validation-report·README 3자를 다시 맞춰야 한다.
- **Phase 1 의 폰트 교체는 모든 화면의 줄바꿈을 바꾼다.** 48px 타깃·가로 넘침 검사가
  먼저 걸릴 수 있고, 그게 안전망이다.
- 8/16 제출까지 닷새. Phase 1~3 은 하루, Phase 4 는 반나절 + 제출물 재생성으로 본다.
