# submission-output

`npm run participant:package` 가 만든 최종 제출 폴더가 여기에 생깁니다.

```
submission-output/<팀ID>/
├── participant-submission.json   공식 재실행 대상
├── simulation-evidence.json      실행 증거
├── submission.sha256             무결성
├── validation-report.md          검증 요약
├── environment-version.json      환경·버전
└── README.md                     팀 소개 (빈칸을 채우세요)
```

이 폴더는 여러분이 만드는 것이므로 버전 관리에서 제외해도 됩니다.

[FINAL_SUBMISSION_CHECKLIST.md](../FINAL_SUBMISSION_CHECKLIST.md) 를 확인한 뒤 제출하세요.
